## Project Euler Solutions

These are my solutions for Project Euler. My goal is to try and solve the first one hundred problems. I was originally using C to solve these problems, however, I switched to Python. Although it would be a fun challenge to try and solve these problems with C, I just found Python to be a more enjoyable language to use because it is more advanced compared to C. My solutions are not the most efficient or best ways to approach these problems, but they do work and achieve the right answer. 

### What is Project Euler? 

<em>Project Euler is a series of challenging mathematical/computer programming problems that will require more than just mathematical insights to solve. Although mathematics will help you arrive at elegant and efficient methods, the use of a computer and programming skills will be required to solve most problems.

The motivation for starting Project Euler, and its continuation, is to provide a platform for the inquiring mind to delve into unfamiliar areas and learn new concepts in a fun and recreational context.</em> - [Project Euler](https://projecteuler.net/)
